# Data Policy

## Allowed processing inputs

Only public-source PDFs or user-provided PDFs should be processed by this project.

## Repository restrictions

- Do not commit downloaded PDFs unless they are clearly public samples and necessary for testing.
- Do not commit organization-specific datasets.
- Do not commit manually collected internal school lists.
- Do not commit real student information.
- Use sample files only for demonstration.

## Runtime data boundary

If a user needs private university indexes, organization-specific tables, or any other non-public reference files, they must be stored outside the public repository and provided at runtime.

## Sample data principle

Any sample data included in the repository should be minimal, replaceable, and suitable for demonstration only.
