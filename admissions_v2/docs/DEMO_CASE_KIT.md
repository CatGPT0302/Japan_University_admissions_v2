## 理科不是所有课程都一样

| 课程 | 理科要求 |
| --- | --- |
| 応用生物学課程 | 物理、化学、生物中选2科 |
| 応用化学課程 | 物理和化学必考；生物栏为横线 |
| 電子システム工学課程 | 物理必考，再从化学、生物中选1科 |
| 情報工学課程 | 物理必考，再从化学、生物中选1科 |
| 機械工学課程 | 物理必考，再从化学、生物中选1科 |
| デザイン・建築学課程 建築コース | 物理、化学、生物中选1科 |
| デザイン・建築学課程 デザインコース | 物理、化学、生物中选1科 |

依据是PDF第4页（印刷页码1）的表格。电子、信息、机械的“化学・生物から1科目”是跨三行的合并单元格，必须应用于三条记录。超过指定科目数时，采用指定科目中的高分科目，不应误写成所有理科分数相加。

建筑与设计按两个申请方向分别整理，因为募集表分别列出，网上出愿注册后不可更改课程或方向。面试时，如有相关作品应带照片或图纸等并说明，没有作品则不要求。

## 勘误必须优先读取

PDF第3页将原来的“留学以外且可以变更为留学的在留资格”，更正为“留学以外、大学入学无障碍的在留资格”。数据保留更正后的条件，不沿用旧句子。第6页另外说明，作为外国人留学生对待需要“留学”资格。这两点不能合并成“所有人必须改成留学”。

这是对文档内容的整理，不是对任何人的在留资格或报考资格判断。基础资格A～G、对应证明材料和个别情况仍需查阅原文并向大学确认。
