# 真实用户试用记录

状态：尚未开展。本文是试用模板，不是用户反馈或验收结论。

## 目的与边界

邀请 1–2 位愿意参加的同学，检查整理结果是否容易理解、是否能回到 PDF 核实。提前说明这是学生个人项目，AI 提取结果可能有误，不能直接作为报考依据。使用公开 PDF，不收集姓名、成绩、账号等个人信息；未经同意不录音、不截图。

## 主持人准备

先确认演示能启动，准备同一批公开 PDF 和待复核结果。保留文件的实际招生年度。让参与者自己操作，不先解释每个按钮；遇到阻碍时可以帮助，但记录帮助发生在哪里。参与者可随时停止。

## 试用任务

1. 找出一个学科的申请截止时间，说明是必着还是消印有效，并打开原文依据。
2. 说明该学科需要哪些 EJU 科目，数学课程是什么；遇到理科三选二时，解释哪些组合被允许。
3. 找到一处待复核信息，说明为什么不能直接相信当前值。原文矛盾未解决时，不要为了完成任务而确认。
4. 在演示数据中修改一处已经核实的字段，保存后重新打开，检查修改是否保留。
5. 查看可读结果，指出最难理解或缺少的内容。

## 改进与复测

每项改动记录：反馈编号、实际问题、改动前后差异、对应测试、同一参与者重试结果。优先处理 1–2 个影响理解或完成任务的问题，而不是增加新功能。无法联系参与者复测时标注“待复测”，不能宣称问题已获得用户验证。
