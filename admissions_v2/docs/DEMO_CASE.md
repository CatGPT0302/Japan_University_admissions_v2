# 福井大学：从 PDF 到待复核数据

这是一份 **2027 年度工学部私费外国人留学生选拔（综合型选拔）的阅读草稿**。五个学科的数据均未经过人的最终确认，不可直接作为报考依据。这里的申请和考试发生在 2026 年，不要把招生年度当成申请日期。

## 必须复核的事

**TOEFL 有效期写法不一致。** PDF 第 10 页的资格要求写“2025 年 1 月以后”，第 12 页的材料说明写“2024 年 10 月以后”。应向大学确认适用规则，并保存答复来源、日期和处理结论；不要让 AI 猜哪个正确，也不要为了演示通过而勾选已确认。

此外，Test Taker Score Report 和 Official Score Report 两种材料都需要在期限内到达；DI 代码为 0184。报考资格有八种基础资格路径，材料也随资格、居住地及面试方式变化，摘要不能替代原文逐项检查。

## 这个案例展示什么

用户需要的是“我应考哪些科目”，不是几个含义不清的符号。因此三个理科字段都保留完整的“三选二”条件。可选组合是物理与化学、物理与生物、化学与生物；不是任意一科即可。

日期规则也必须分开：出愿有指定邮寄方式的消印例外，入学手续没有同样的例外。系统应保留区别，而不是把两个字段都缩写成“截止日期”。

以上是设计案例与技术验证，不是已收到的用户反馈。

## 复现导入

在仓库根目录运行，先校验再导入：

```bash
.venv/bin/python -m scripts.import_demo_data examples/demo/fukui_2027_codex.json --source-pdf data/uploads/fukui_engineering_2027_undergrad.pdf
.venv/bin/python -m scripts.import_demo_data examples/demo/fukui_2027_codex.json --source-pdf data/uploads/fukui_engineering_2027_undergrad.pdf --apply
```

PDF 不随 Git 仓库分发。源文件来自福井大学公开文档：
[2027 年度募集要项](https://www.u-fukui.ac.jp/wp/wp-content/uploads/bsy27_shihiryu_youkou.pdf)。将相同文件放到上述路径；如果大学替换了文件，指纹校验会拒绝导入，应重新阅读新文件，而不是直接修改指纹绕过检查。

默认只校验；加 `--apply` 才会写入 `runtime/local_demo` 下的独立演示库。相同数据包重复运行不会重复添加或覆盖人工修改。导入不进行模型调用，不写入已确认记录。结构与页码校验通过不代表事实已经正确，仍须人工复核。

若导入进程意外中断并留下不完整文档，导入器会停止重试；先在演示库检查该文档，不要直接删除原始资料。当前入口面向单人本地演示，不承诺并发导入。
