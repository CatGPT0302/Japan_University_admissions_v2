# Ownership Notice

## Project Ownership

This project is a personal project independently created, developed, and maintained by the author.

It is not an organizational asset, commissioned work product, or jointly owned system unless a separate written agreement explicitly states otherwise.

## Trial Boundary

Any third party may only access:

- exported results such as Excel outputs
- screenshots or walkthrough materials
- an author-approved demo environment

Trial access does not include operational control or transfer of the underlying system.

## Not Delivered by Default

The following are not delivered, transferred, or shared by default:

- source code
- GitHub admin or repository management rights
- Railway or Vercel deployment access
- database files, database access, or database management rights
- prompts or prompt templates
- extraction workflow details
- batch processing scripts
- review rules or review logic

## Deliverables That May Be Provided

If the author chooses to provide limited trial materials, they may include:

- Excel export results
- demo screenshots
- limited-time access to an approved demo environment

## Formal Use

Any formal use, continued access, operational handoff, or expanded rights requires a separate written agreement signed by the relevant parties.
