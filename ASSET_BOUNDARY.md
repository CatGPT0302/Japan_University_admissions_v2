# Asset Boundary

## Personal assets

The following are personal project assets maintained by the author:

- code implementation
- system architecture
- extraction pipeline
- review workflow
- confidence/evidence/risk logic
- UI
- database integration
- export workflow
- product roadmap

## External / non-owned assets

The following are not treated as repository-owned product assets:

- university lists
- third-party indexes
- custom field templates
- manually collected non-public tables
- private business data

## Rule

External, private, or custom assets must be kept outside the public repository and loaded only as user-provided runtime data.

If runtime data is needed, it should be supplied through user-managed files such as `private_data/` or another user-controlled path outside the repository.

## Trial usage

Organizations may test outputs or use exported Excel files only with explicit permission from the author.

Such trial use does not transfer ownership of the system.
