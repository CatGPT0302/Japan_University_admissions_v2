# 本地演示

## 项目定位

这是一个 AI 辅助开发的个人招生信息整理原型，不是正式招生服务。
先演示一份官方 PDF 从结构化整理、人工复核到查询的完整过程。
只在自己的电脑上运行，不对公网开放。

## Mac 启动

依赖已经准备好后，双击项目根目录的 `start_demo.command`。
也可以在项目目录运行：

```sh
.venv/bin/python -m scripts.local_demo
```

启动器会构建独立的演示前端，默认地址为 `http://127.0.0.1:8765`。
如果端口被占用，会选择空闲端口；以终端实际显示的地址为准。
前后端共用该地址，不需要分别启动两个服务器。

演示账号可输入 `demo` 或 `demo@localhost`；首次生成的随机密码保存在
`runtime/local_demo/access.json`，只需首次登录时查看，不要提交或分享此文件。
重新启动不会重置演示密码，也不会清空演示数据。
关闭窗口或按 Ctrl+C 停止服务。修改代码后再次启动，会重新构建前端。

## 学生注册

在管理端点击“学生入口”，或打开 `/#/student`，再点击“登录 / 我的账号”。
学生可自行注册；管理员通过独立的终端命令创建，不能公开注册。
详见[账号说明](ACCOUNTS.md)。

## 新电脑准备

需要 Python 3.11+ 和 Node.js 20+（包含 npm）。在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt httpx
cd frontend
npm ci
cd ..
chmod +x start_demo.command
```

启动器也能识别 Codex 桌面应用的配套 Node 运行时；它不修改系统运行时。
没有依赖时应按上述方式安装，不要将虚拟环境复制到另一台电脑。

## 数据边界

- 演示数据库：`runtime/local_demo/data/admissions.db`。
- 演示上传、导出、日志与账号均在 `runtime/local_demo/` 内。
- 原始 `data/admissions.db` 不用于演示。
- 不继承原有管理员、合作方或 PostgreSQL 连接设置。
- 此模式禁用服务端模型抽取；由 Codex 直接阅读 PDF，程序负责导入与复核。
- 结果必须人工核对后才能确认，未确认记录不应出现在正式查询中。
- 示例文档保留实际年度，不能把历史样例当成最新招生建议。

## 当前限制

软件测试与浏览器检查不能代替真实同学试用。用户反馈、节省时间、
最终数据准确性均需另外验证，不以一份 PDF 成功推断所有学校都能成功。
依赖安装报告了安全告警，公开部署前需要单独审查；本轮仅做本机演示。
