修复后测量：390/1024/1440/1920px视口的文档scrollWidth分别为390/1024/1440/1920px。对应复核网格为单栏、双栏、双栏和三栏；中等宽度词条列表放在两栏上方，并限制列表滚动高度。标题使用固定28px字号。已查看手机字段/证据截图与桌面对照截图，PDF图像加载成功。PDF自身滚动范围保留，不能把页面无溢出误解为整页PDF在任意尺寸下都无需缩放。

TypeScript/Vite演示构建通过。上述是布局技术验收，不是用户满意度评估；完整浏览器确认和下载动作仍需独立测试。
