# 案头前端 UI 优化设计稿

## 目标

本次只改 `frontend/` 的 UI 与交互层，不修改后端逻辑、数据库 schema、API contract、sample data。

目标是将当前产品重构为一个更像成熟桌面工具的工作台界面，整体气质靠近苹果官网的克制感，同时保留 Notion 式的秩序与可读性。

UI 内不保留任何开发过程遗留的技术说明、设计说明、Prompt 风格文案、系统自述或 AI 味过重的表达。

## 产品命名

- UI 中的产品名称统一改为 `案头`
- 原 `admissions_v2` 不再作为主界面品牌名出现
- 功能副标题只保留业务短语，例如 `导入、复核、记录`

## 设计方向

### 总体风格

- 整站采用 `Liquid Glass` 风格，而不是局部点缀
- 视觉气质参考苹果官网的轻玻璃、柔和模糊、低对比层级
- 信息秩序参考 Notion，强调留白、稳定结构、内容优先

### 视觉原则

- 背景使用浅灰白雾面，不使用大面积纯白
- 一级容器统一使用半透明白底、细边框、轻模糊、弱阴影
- 颜色保持克制，主色只在选中、聚焦、链接和关键状态中少量使用
- 风险、成功、警告状态降低饱和度，避免后台模板式大色块
- 标题、正文、辅助文字建立严格的三层以上对比层级

### 文案原则

- 页面只保留业务动作语言，不解释界面设计
- 删除技术流程说明、实现提示、开发占位文案
- 不出现 `Prompt`、`AI`、`系统说明`、`设计说明` 等表达
- 全站默认中文

## 信息架构

### 全局结构

- 左侧固定主导航，作为所有一级入口的唯一容器
- 一级导航只保留 `导入`、`复核`、`记录`
- 右侧为当前工作区，不额外堆叠营销式横幅或技术说明
- 顶部仅展示当前页面名与少量上下文状态

### 交互结构

- 所有列表项支持左键进入二级详情界面
- 二级界面统一包含返回入口，避免用户丢失层级位置
- 页面内所有操作入口尽量收拢到左侧操作栏
- 主内容区域优先展示正在处理的对象，而不是操作说明

## 页面设计

### 1. 导入

#### 左侧

- 放置全部入口与参数
- 包含上传、本地检索、指定链接、学校名称、年份、来源页、开始处理
- 保留清空和来源检查等辅助操作

#### 右侧

根据状态切换为四类内容：

- 空态
- 上传投递区
- 候选来源列表
- 处理结果

#### 导入交互要求

- 上传区像工作台投递面板，不像宣传区块
- 候选来源可左键选中
- 当前选中的来源应有清楚但克制的高亮
- 完成处理后，结果区直接提供 `进入复核`

### 2. 复核

#### 左侧

- 文档列表
- 搜索
- 年份筛选
- 刷新

#### 右侧

两级结构：

- 第一级为当前文档下的记录队列
- 第二级为单条复核详情

#### 复核交互要求

- 文档列表左键进入当前文档
- 文档内记录左键进入单条复核详情
- 详情区只保留字段、证据、风险、保存、下一条、整份入库
- 风险等级与复核状态清楚可见，但不过度强调色块
- 高风险未处理时，需要继续保留整份入库的限制

### 3. 记录

#### 左侧

- 学校、学部、年份筛选
- 执行检索
- 导出当前结果
- 清空筛选

#### 右侧

两级结构：

- 第一级为记录列表
- 第二级为记录详情

#### 记录交互要求

- 列表卡片只保留必要摘要
- 详情页更像档案页，不像编辑表单
- 图表只作为辅助信息，不抢主流程

## 组件规则

### 导航

- 使用统一的侧边栏导航卡片
- 每项包含短标题和一行辅助说明
- 当前项高亮采用轻玻璃提亮，不用重色块

### 列表卡片

- 统一使用玻璃卡片语言
- 标题、次信息、标签和摘要的间距一致
- hover 与 selected 都要清楚但轻

### 详情容器

- 统一使用更高层级的玻璃卡片
- 保证字段分组和留白清晰
- 二级详情都提供稳定的返回入口

### 按钮

- 每个区域只允许一个主按钮
- 次级操作使用低强调按钮
- 危险操作独立分组显示

### 状态标签

- 全部统一为低饱和、细边界、短文本
- 语义清晰，但不做大面积高对比色块

## 动效规则

- 只使用轻微过渡，不做显眼动画
- 主要用于 hover、选中、进入详情、状态切换
- 动效服务于层级连续性，不做装饰性表演

## 约束

- 不修改后端接口
- 不修改数据库 schema
- 不修改 sample data
- 不扩大功能范围
- 不新增与当前业务无关的功能模块

## 实施顺序

1. 统一全局品牌、导航和工作区骨架
2. 重构 `导入`、`复核`、`记录` 的左右结构
3. 统一列表到详情的二级界面逻辑
4. 统一 Liquid Glass 视觉系统与组件样式
5. 清理所有技术说明类文案

## 验收标准

- UI 主品牌已从 `admissions_v2` 切换为 `案头`
- 左侧成为所有一级入口的主容器
- `复核` 和 `记录` 中每条数据都能左键进入二级界面
- 全站文案去除技术痕迹与 AI 味说明
- 整体观感明显接近成熟工具产品，而不是开发态后台
- 前端构建通过
